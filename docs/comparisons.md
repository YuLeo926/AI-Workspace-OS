# Comparisons

AI Workspace OS is intentionally narrower than most agent frameworks.

## Agent Runtimes

Agent runtimes coordinate tools, tasks, memory, and agent execution.

AI Workspace OS does not run agents. It gives human-supervised agents a file protocol for continuity, ownership, auditability, and recovery.

## Vector Memory Systems

Vector memory systems retrieve prior context.

AI Workspace OS does not replace retrieval. It defines the files that should remain authoritative when retrieved context, chat history, and local notes disagree.

## Dashboards

Dashboards visualize status.

AI Workspace OS starts before a dashboard is needed: with plain files an agent can read, write, review, and recover from.

## Multi-Agent Company Simulations

Company simulations model many roles and workflows.

AI Workspace OS keeps role patterns optional. A solo user can start with coordinator, lead, and worker, then add structure only when useful.

## When to Use Both

Use AI Workspace OS alongside agent frameworks when:

- sessions last longer than one chat;
- agents need explicit write boundaries;
- decisions need to survive context resets;
- recovery and audit trails matter.
